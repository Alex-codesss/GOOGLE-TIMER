# GOOGLE TIMER

GOOGLE TIMER는 갤럭시탭에서 탁상시계처럼 사용하는 시각형 집중 타이머입니다. 남은 시간이 줄어들수록 원형 다이얼의 색칠된 부채꼴도 줄어듭니다.

**실행:** https://alex-codesss.github.io/GOOGLE-TIMER/

로그인이나 설치 없이 웹 브라우저에서 바로 사용할 수 있는 공개 버전입니다.

## 모바일 앱 (Android / Apple)

[모바일 버전 다운로드](https://github.com/Alex-codesss/GOOGLE-TIMER/releases/tag/mobile-v5.0.0)에서 Android APK와 iOS 소스를 받을 수 있습니다. 별도 네이티브 프로젝트를 [native/](native/)에 준비했습니다. 설치·빌드 방법은 [모바일 안내](native/README.ko.md)를 확인하세요. Android APK는 GitHub Actions로 빌드하며, iOS 프로젝트는 Mac/Xcode에서 기기 서명 후 설치할 수 있습니다. 네이티브 앱에는 타이머를 내장하므로 ChatGPT 로그인과 인터넷 연결이 필요하지 않습니다.

## 주요 기능

- **다이얼 인터랙션**: 터치 드래그 또는 키보드 방향키로 1~60분 조절
- **빠른 프리셋**: 5·10·25·50분 원터치 선택 및 시작·일시정지·초기화
- **4종 감성 알람 사운드**: 맑은 차임벨, 싱잉볼 명상종, 차분한 목탁/우드블록, 스마트 디지털 비프 (Web Audio API 기반 100% 오프라인 지원)
- **6종 테마 컬러 팔레트**: 클래식 코랄, 구글 레드, 포레스트 그린, 스카이 블루, 앰버 골드, 미드나잇 퍼플
- **뽀모도로 루틴 모드**: 25분 집중 + 5분 휴식의 4회차 연속 사이클 및 휴식 전용 민트 다이얼 전환
- **오늘의 집중 통계**: 하루 동안 누적된 집중 시간(분) 및 완료 횟수 실시간 저장/표시
- **웹 화면 내 앱 다운로드**: 웹 화면 상단의 [앱 다운로드] 버튼으로 안드로이드 APK 및 iPad 패키지를 즉시 내려받거나 PWA로 기기에 바로 설치 지원
- **오조작 방지 화면 잠금**: 드래그, 3자리 비밀번호, 3×3 패턴 잠금 해제 지원
- **화면 및 숫자 표시 옵션**: 집중 전용 화면 vs 원래 화면 유지, 카운트다운/다이얼 숫자 개별 숨김
- **종료 시 전체 화면 점멸**: 현재 화면을 유지한 채 전체가 깜박이며, 기본 10초 뒤 자동 정지 (5~60초 선택)
- **상태 보존**: 새로고침이나 재접속 시에도 타이머 진행 상태와 설정값 완벽 복원

## 사용 방법

1. 시간을 설정하고 **집중 시작**을 누릅니다.
2. 설정에 따라 타이머 전용 화면 또는 원래 화면을 유지하고, 자동 잠금을 켠 경우 조작 화면이 잠깁니다.
3. 타이머 전용 화면에서 화면을 누르면 복귀 버튼이 나타납니다. 자동 잠금을 끄면 비밀번호 없이 돌아갈 수 있습니다.
4. **설정 → 테마 및 사운드**에서 4가지 알림음과 6가지 테마 컬러를 취향대로 고를 수 있습니다.
5. **설정 → 뽀모도로 루틴 모드**를 켜면 집중과 휴식이 자동으로 연계되는 생산성 루틴을 사용할 수 있습니다.

## 로컬 실행

Node.js 패키지 설치나 빌드 과정 없이 동작하는 HTML/CSS/JavaScript 앱입니다. Python이 설치되어 있다면 저장소 루트에서 실행합니다.

```sh
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 기기에서 사용하려면 HTTPS로 정적 호스팅하세요. 화면 켜짐 유지, 비밀번호·패턴 해시 처리와 서비스 워커는 HTTPS 또는 localhost 환경이 필요합니다.

## 버전 보관

| 태그 | 내용 |
| --- | --- |
| `v1.0.0` | 최초 타이머 버전 |
| `v2.0.0` | 집중 화면 및 드래그·비밀번호·패턴 잠금 추가 |
| `v3.0.0` | 잠금·화면 유지·숫자 표시·종료 깜박임 선택 |
| `v4.0.0` | 현재 화면 전체 깜박임, 기본 10초 후 정지 및 화면 유지 |
| `v5.0.0` | 감성 사운드 팩(4종), 6종 테마 컬러, 뽀모도로 루틴 모드, 오늘 집중 통계 |

각 태그를 선택하면 해당 버전의 소스를 내려받을 수 있습니다. 변경 내역은 [CHANGELOG.md](CHANGELOG.md), 확인 기록은 [VALIDATION.md](VALIDATION.md)에 있습니다.

## 파일 구조

- `dist/`: 배포 가능한 정적 웹 앱
- `dist/app.js`: 다이얼, 사운드, 테마, 뽀모도로 및 통계 동작
- `dist/lock.js`: 잠금 화면과 비밀번호·패턴 설정
- `dist/sw.js`: 기본 오프라인 리소스 캐시
- `native/`: Android / iOS 네이티브 래퍼 프로젝트
- `.openai/hosting.json`: 기존 Sites 배포 구성
