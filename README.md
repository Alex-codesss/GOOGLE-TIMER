# GOOGLE TIMER

GOOGLE TIMER는 갤럭시탭에서 탁상시계처럼 사용하는 시각형 집중 타이머입니다. 남은 시간이 줄어들수록 원형 다이얼의 색칠된 부채꼴도 줄어듭니다.

**실행:** https://focus-dial-rgann.rgann001.chatgpt.site/

현재 배포 주소는 소유자 전용이며, GitHub 저장소의 소스 코드는 별도로 실행할 수 있습니다.

## 기능

- 다이얼 터치 또는 키보드 방향키로 1~60분 설정
- 5·10·25·50분 빠른 선택, 시작·일시정지·초기화
- 종료 소리 및 화면 알림, 색상·야간 모드, 화면 켜짐 유지
- 시작 시 자동 잠금과 작동 화면을 독립적으로 선택
- 화면 터치 후 잠금 해제 버튼 표시
- 드래그, 3자리 비밀번호 또는 3×3 패턴으로 잠금 해제
- 새로고침 후 타이머와 잠금 상태 복원
- 태블릿 가로·세로 화면 대응 및 홈 화면 추가용 웹 앱 매니페스트

## 사용 방법

1. 시간을 설정하고 **집중 시작**을 누릅니다.
2. 설정에 따라 타이머 전용 화면 또는 원래 화면을 유지하고, 자동 잠금을 켠 경우 조작 화면이 잠깁니다.
3. 타이머 전용 화면에서 화면을 누르면 복귀 버튼이 나타납니다. 자동 잠금을 끄면 비밀번호 없이 돌아갈 수 있습니다.
4. **설정 → 화면 잠금 → 잠금 해제 방법**에서 드래그·비밀번호·패턴을 선택합니다.

비밀번호와 패턴은 두 번 입력해 등록합니다. 설정은 브라우저의 로컬 저장소에 저장되며, 다른 기기와 동기화되지 않습니다. 비밀번호·패턴을 잊었다면 해당 사이트의 브라우저 데이터를 삭제해 초기화할 수 있습니다. 이때 타이머 설정도 초기화됩니다.

잠금은 타이머 내부의 오조작 방지 기능이며, Android 자체를 잠그거나 다른 앱으로 이동하는 것을 막지는 않습니다. 알림을 받으려면 화면을 열어 두세요. 소리와 화면 켜짐 유지는 기기·브라우저의 설정에 영향을 받습니다.

## 작동 화면 선택 (v3)

**설정 → 작동 화면**에서 각각 선택할 수 있습니다.

- 시작 시 자동 잠금: 켜기 / 끄기
- 작동 중 원래 화면 유지: 켜면 제목·버튼을 유지하고, 끄면 타이머 전용 화면으로 전환
- 작동 중 남은 시간 숫자 표시: 디지털 카운트다운 표시 / 숨김
- 작동 중 다이얼 숫자 표시: 원 둘레의 숫자 표시 / 숨김
- 종료 시 시계 깜박임: 종료 후 다이얼과 숫자가 천천히 깜박이며, 화면을 누르면 정지

화면·잠금 선택은 다음 시작부터 적용되며, 숫자 표시는 실행 중에도 설정을 바꾸면 적용됩니다. 원래 화면 유지와 잠금을 모두 켜면 기존 화면이 보이면서 조작만 잠깁니다. 숫자를 숨긴 경우에도 일시정지나 종료 시 다시 표시됩니다. 모든 선택은 기기에 저장됩니다. 시스템의 동작 줄이기 설정이 켜져 있으면 더 느리고 은은한 깜박임과 테두리로 알립니다.

## 로컬 실행

Node.js 패키지 설치나 빌드 과정 없이 동작하는 HTML/CSS/JavaScript 앱입니다. Python이 설치되어 있다면 저장소 루트에서 실행합니다.

```sh
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 기기에서 사용하려면 HTTPS로 정적 호스팅하세요. 화면 켜짐 유지, 비밀번호·패턴 해시 처리와 서비스 워커는 HTTPS 또는 localhost 환경이 필요합니다.

## 버전 보관

| 태그 | 내용 |
| --- | --- |
| `v1.0.0` | 최초 타이머 버전 |
| `v2.0.0` | 집중 화면 및 드래그·비밀번호·패턴 잠금 추가 |
| `v3.0.0` | 잠금·화면 유지·숫자 표시·종료 깜박임 선택 |

각 태그를 선택하면 해당 버전의 소스를 내려받을 수 있습니다. 변경 내역은 [CHANGELOG.md](CHANGELOG.md), 확인 기록은 [VALIDATION.md](VALIDATION.md)에 있습니다.

## 파일 구조

- `dist/`: 배포 가능한 정적 웹 앱
- `dist/app.js`: 다이얼 및 타이머 동작
- `dist/lock.js`: 잠금 화면과 비밀번호·패턴 설정
- `dist/sw.js`: 기본 오프라인 리소스 캐시
- `.openai/hosting.json`: 기존 Sites 배포 구성

외부 코드의 복사 없이 직접 구현했습니다. 외부 리소스로 Google Fonts의 Noto Sans KR을 불러오며, 연결되지 않으면 기기의 기본 글꼴을 사용합니다.
